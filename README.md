# 📰 Prism: 하나의 자료, 여러 시선


**🔭 통계 보도자료에서 시작해, 다양한 뉴스로 시선을 확장하다.**

Prism은 국가데이터처의 통계 보도자료를 기준으로 관련 뉴스를 수집·제공하는 뉴스 포털입니다. 국가데이터처 RSS에서 보도자료 제목을 수집하고, 네이버 뉴스 검색 API를 통해 관련 기사를 검색합니다. 이후 기사 본문과 대표 이미지 등을 추출하여 이용자가 통계와 관련된 뉴스를 탐색할 수 있도록 구성하였습니다.

이용자는 뉴스 목록에서 관심 있는 기사를 선택하고, 기사에 연결된 통계자료를 눌러 관련된 주장과 상반된 주장을 비교할 수 있어요. 같은 통계 주제가 언론에서 어떻게 다뤄지는지 기사 발췌문과 원문 링크를 통해 살펴볼 수 있어요.

## 🔍 분석 방법

1. **RSS 수집:** 국가데이터처 보도자료 RSS에서 제목·원문 링크·발행일·자료 ID를 확보해요. 개최·채용·모집·워크숍·세미나·포럼·조사 실시 안내는 검색 대상에서 제외해요.
2. **뉴스 검색:** RSS 제목과 발행기관명으로 네이버 뉴스 검색 API를 호출하고, 필요할 때 통계 주제·기간을 활용한 확장 검색을 수행해요.
3. **결과 정리:** 수집한 뉴스의 중복을 제거하고 날짜·검색 기준·검색 순위를 저장해요.
4. **본문 추출:** 보도자료 근거와 기사 본문·대표 이미지·언론사 정보를 확보하고 처리 상태를 기록해요.
5. **자료 연결 및 주장 분석:** 본문에서 자료명·링크·기간·수치 등을 확인하고, 같은 자료와 비교 가능한 문장을 바탕으로 관련 주장과 상반 주장 후보를 분석해요.
6. **웹 데이터 생성:** 결과를 검증해 `web/snapshots/`에 저장한 뒤 `web/current.json`을 교체해요. 발행이 완료되기 전에 실패하면 이전 화면 데이터를 유지해요.
7. **서비스 제공:** 뉴스 목록, 검색·필터·페이지 이동, 기사 상세 화면 및 주장 비교를 제공해요.

기사 본문 추출은 언론사별 페이지 구조와 `robots.txt`, 서버 응답 등에 따라 성공 여부가 달라질 수 있어요. 본문을 확보하지 못한 경우에는 요약문과 원문 링크를 제공해요. 발표 일정만 언급하거나 자료 발표일보다 앞선 기사만으로 자료 사용을 확정하지 않아요.

## 🏆 주요 구현 결과

### 통계 보도자료 기반 뉴스 수집

국가데이터처의 통계 보도자료를 뉴스 검색의 출발점으로 활용하여, 통계 주제별로 관련 기사를 수집하는 구조를 구현하였습니다.

수집한 기사에는 검색 기준이 된 보도자료 정보를 연결하여, 이용자가 해당 기사가 어떤 통계 주제와 관련되어 수집되었는지 확인할 수 있도록 구성하였습니다.

### 기사 본문 및 대표 이미지 제공

언론사 원문 페이지에서 기사 본문과 대표 이미지 정보를 추출하여 뉴스 상세 화면에 활용합니다.

본문 추출에 실패한 경우에는 검색 API에서 제공하는 요약문을 대신 표시하도록 처리하여, 원문 수집 결과에 따른 화면 공백을 줄였습니다.

### 연관 기사 탐색

기사 상세 화면에서 통계자료 이름을 선택하면 같은 자료에 연결 근거가 있는 다른 기사의 주장을 비교할 수 있어요.

관련된 주장과 상반된 주장을 구분하고, 양쪽 발췌문·발언 주체·비교 맥락·원문 링크를 함께 제공해요. 검색으로 연결된 후보 기사도 일반 목록에서 탐색할 수 있어요.

## ✨ 주요 기능


- **뉴스 목록 제공:** 기사 제목·이미지·요약문·언론사·발행일을 카드로 표시하고, 24건씩 페이지를 이동해요.
- **뉴스 검색:** 검색어와 통계자료 필터를 이용하고, 자료 연결 근거가 있는 기사만 따로 볼 수 있어요.
- **기사 상세 화면:** 선택한 기사의 제목, 본문 또는 요약문, 대표 이미지 등 표시
- **연관 기사 탐색:** 같은 통계자료에 연결된 기사의 관련 주장과 상반된 주장을 비교해요.
- **뉴스 정렬:** 최신순 또는 다양한 언론사순으로 기사 목록을 정렬해요.
- **본문·이미지 대체 표시:** 원문 본문을 확보하지 못한 경우 검색 API 요약문 활용
- **반응형 화면:** PC와 모바일 환경에 대응하는 뉴스 포털 레이아웃
- **데이터 갱신:** 수집·본문 처리·분석·검증을 마친 뒤 화면 데이터를 한 번에 교체해요.

## 📁 프로젝트 폴더 구조

`Prism/`은 로컬 프로젝트 폴더예요. GitHub ZIP으로 내려받으면 최상위 폴더 이름이 `Prism-main/`일 수 있어요. 아래에서 **[생성]** 표시는 설정 또는 수집·가공 과정에서 추가되는 항목입니다.

```text
Prism/
├── .env.example                    # 공유용 환경변수 예시
├── .env                            # [생성] 개인 환경설정, Git 제외
├── .gitignore                      # Git 추적 제외 규칙
├── README.md                       # 프로젝트 설명 및 실행 안내
├── requirements.txt                # Python 의존성 목록
├── prism.py                        # 수집·분석·발행·로컬 서버 CLI
│
├── prism_core/
│   ├── common/                     # 설정·파일·HTTP 요청·파이프라인 잠금
│   ├── collection/                 # RSS·뉴스·본문·보도자료 근거 수집
│   ├── analysis/                   # 자료 연결 근거 및 주장 분석
│   └── publishing/                 # 검증·스냅샷 발행·비교 예시 데이터
├── config/article_selections.json  # 비교 예시 2쌍의 설정
├── .models/                       # [생성] 로컬 모델, Git 제외
│
├── data/                          # [생성] 로컬 수집·분석 자료, Git 제외
│   ├── selected_sources/          # 비교 예시 기사 처리 결과
│   └── news_<실행시각>/            # 수집 실행별 결과
│       ├── rss_titles.json         # RSS 제목 목록
│       ├── rss_releases.json       # 자료 ID·원문 링크·발행일
│       ├── articles.jsonl          # 중복을 정리한 기사 목록
│       ├── analysis.json           # 자료 연결·주장 분석 결과
│       ├── pipeline_log.json       # 수집·처리·분석·발행 로그
│       ├── raw/                    # 검색어별 네이버 API 원응답
│       ├── references/             # 보도자료 원문과 근거
│       └── bodies/                 # 기사별 HTML·본문·메타데이터
│
└── web/
    ├── index.html                  # 뉴스 포털 HTML 구조
    ├── demo.json                   # 저장소에 포함된 비교 예시 데이터
    ├── current.json                # [생성] 현재 발행 스냅샷 경로
    ├── snapshots/                  # [생성] 검증된 웹 데이터
    └── assets/
        ├── css/
        │   └── styles.css          # 반응형 웹 디자인
        ├── js/
        │   ├── app.js              # 목록·검색·상세·주장 비교
        │   ├── comparison-data.mjs # 자료 연결 및 비교 관계 조회
        │   ├── data-loader.mjs     # 데이터 로딩
        │   └── format.mjs          # 텍스트·날짜 표시
        └── images/
            ├── cover.svg           # 기본 기사 이미지
            └── prism.svg           # Prism 로고
```

수집 결과와 웹 스냅샷은 로컬에서 생성하는 산출물이에요. 새 복제본에는 `web/demo.json`이 포함되어 있어 API 키나 모델 없이도 비교 예시 2쌍을 일반 기사 목록과 비교 화면에서 볼 수 있어요. 데이터를 수집·발행하면 해당 스냅샷을 우선해서 표시해요.

다음 파일 및 폴더는 실행 환경이나 데이터 수집 과정에서 생성·관리되며, Git 추적 대상에서 제외돼요.

| `.env` | 개인 API 인증정보 및 로컬 환경 설정 |
| `.venv/` | Python 가상환경 |
| `.models/` | 로컬 NLI 모델 파일 |
| `data/` | 뉴스 수집·본문·분석 결과, 캐시 및 로그 |
| `web/current.json` | 현재 발행 데이터 경로 기록 |
| `web/snapshots/` | 뉴스 포털에서 사용하는 웹 데이터 |
| `__pycache__/` | Python 실행 과정에서 생성되는 캐시 |

## 🚀 이용 및 실행 방법

Prism은 Python으로 뉴스를 수집·분석하고, **로컬 웹서버를 통해 뉴스 포털을 실행**하는 구조예요.

실행 후 브라우저에서 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**에 접속합니다. 뉴스 카드를 선택하면 기사 상세 화면으로 이동하며, 검색창·원문 링크·연관 기사 패널을 이용할 수 있습니다.

### 1. 사전 준비

- Python 3.12 설치 권장
- 뉴스 수집 시 네이버 뉴스 검색 API 인증정보 필요
- 뉴스 수집 및 최초 모델 다운로드 시 인터넷 연결 필요
- Git 및 VS Code 등 개발 도구 사용 권장

아래 설치 명령어는 **Python 3.12 기준**입니다.

먼저 저장소를 복제한 뒤 프로젝트 폴더로 이동합니다.

```bash
git clone https://github.com/Stat-Official/Prism.git
cd Prism
```

화면만 먼저 확인하려면 별도 패키지 설치 없이 macOS에서 `python3.12 prism.py serve`, Windows에서 `py -3.12 prism.py serve`를 실행해요. 뉴스 수집과 분석을 실행할 때는 아래 환경 설정을 진행해요.

### 2. 운영체제별 설치 및 환경 설정

<details>
<summary><strong>macOS 설치 방법</strong></summary>

프로젝트 폴더에서 다음 명령어를 순서대로 실행합니다.

```bash
python3.12 -m venv .venv # Python 가상환경 생성
source .venv/bin/activate # 가상환경 활성화
python -m pip install -r requirements.txt # 필요한 라이브러리 설치
cp -n .env.example .env # 환경변수 예시를 `.env`로 복사, 기존 파일은 유지
```

</details>

<details>
<summary><strong>Windows (PowerShell) 설치 방법</strong></summary>

Python 3.12와 Python Launcher(`py`) 설치 후 프로젝트 폴더에서 다음 명령어를 실행합니다.

```powershell
py -3.12 -m venv .venv  # Python 가상환경 생성
.\.venv\Scripts\Activate.ps1  # 가상환경 활성화
.\.venv\Scripts\python.exe -m pip install -r requirements.txt  # 필요한 라이브러리 설치
if (-not (Test-Path .env)) { Copy-Item .env.example .env }  # `.env`가 없는 경우 환경변수 예시 복사
```

**PowerShell 실행 정책 오류가 발생하는 경우**

`Activate.ps1` 실행이 차단되면 현재 PowerShell 세션에만 실행 정책을 적용한 뒤 다시 활성화합니다.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
```

</details>

### 3. API 및 RSS 환경변수 설정

프로젝트 폴더의 `.env.example`을 복사하여 `.env` 파일을 생성하고, 본인의 인증정보와 설정값을 입력합니다.

| 환경변수 | 설정할 값 |
| --- | --- |
| `NAVER_API_PROVIDER` | 네이버 개발자센터: `developers`, 네이버 클라우드: `ncp` |
| `NAVER_CLIENT_ID` | 본인의 네이버 API 클라이언트 ID |
| `NAVER_CLIENT_SECRET` | 본인의 네이버 API 클라이언트 시크릿 |
| `RSS_URL` | 통계 보도자료 RSS 피드 주소, `.env.example`에 국가데이터처 RSS 주소 제공 |
| `RSS_PUBLISHER` | RSS 발행기관명, 기본 예시: `국가데이터처` |
| `RSS_COUNTRY` | RSS 발행기관의 국가, 기본 예시: `KR` |
| `PRISM_DEVICE` | 필요할 때 모델 실행 장치를 `cpu`, `mps`, `cuda` 중에서 지정 |

`.env` 설정 예시는 다음과 같습니다.

```dotenv
NAVER_CLIENT_ID=YOUR_CLIENT_ID
NAVER_CLIENT_SECRET=YOUR_CLIENT_SECRET
NAVER_API_PROVIDER=ncp

RSS_URL=https://mods.go.kr/board.es?mid=a10301010000&bid=a103010100&act=rss
RSS_PUBLISHER=국가데이터처
RSS_COUNTRY=KR
```

위 설정은 `.env.example`을 기준으로 작성했어요. `PRISM_DEVICE`는 필요한 경우에만 추가해요.

**주의:** `.env`에는 실제 API 인증정보가 포함되므로 GitHub에 업로드하지 않아야 합니다. `.env.example`은 공유용 예시 파일로 유지합니다.

### 4. 뉴스 수집 및 웹페이지 실행

macOS와 Windows 모두 가상환경이 활성화된 상태에서 아래 명령어를 실행해요.

**① 뉴스 수집·본문 처리·분석·발행**

```bash
python prism.py update --limit 10 --per-query 30 --body-limit 60
```

RSS와 네이버 뉴스 검색 결과를 수집하고, 본문 처리·자료 연결·주장 분석·검증을 거쳐 웹 데이터를 발행해요.

| 옵션 | 의미 |
| --- | --- |
| `--limit 10` | 처리할 RSS 보도자료 수를 최대 10건으로 설정 |
| `--per-query 30` | 검색어별 뉴스 검색 결과를 최대 30건으로 설정, `--per-release`와 같은 옵션 |
| `--body-limit 60` | 일반 수집 기사 중 본문 처리 대상을 최대 60건으로 설정 |
| `--query-mode title` | 기본 조건부 확장 검색 대신 제목 검색만 사용 |
| `--analysis-pairs 240` | 자동 분석의 최대 모델 비교 예산 설정, 기본값 240쌍 |
| `--serve` | 발행을 마친 뒤 로컬 웹서버도 실행 |

일반 기사 본문 수집은 실행당 도메인별 최대 6건을 선택하며, `robots.txt` 및 서버 응답에 따라 일부 기사 수집에 실패할 수 있어요.

한국어 NLI 모델은 `Huffon/klue-roberta-base-nli`의 고정 리비전을 사용해요. 모델 비교가 필요한 최초 실행 시 모델을 다운로드하고, 이후에는 로컬 파일과 점수 캐시를 재사용해요. 미리 준비하려면 `python prism.py prepare-model`을 실행해요.

**② 저장된 결과 재처리 및 확인**

필요한 경우 `data/` 아래 실제 수집 폴더 이름을 지정해 재처리해요.

```bash
# Replace the ID with an existing collection folder.
python prism.py update --run news_YYYYMMDD_HHMMSS_microseconds --retry-failed
python prism.py update --run news_YYYYMMDD_HHMMSS_microseconds --reextract
python prism.py report
```

`--retry-failed`는 실패한 요청을 다시 시도하고, `--reextract`는 저장된 HTML에서 본문을 다시 추출해요. `--reextract`에는 `--run`이 필요해요. 다른 단계에서 보도자료 근거가 부족하면 네트워크 요청이 발생할 수 있어요.

**③ 로컬 웹 서버 실행**

```bash
python prism.py serve
```

브라우저에서 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**에 접속해요. 기사에 연결된 통계자료 이름을 누르면 관련된 주장과 상반된 주장을 비교할 수 있어요.

`Address already in use` 오류가 나오면 비어 있는 포트를 지정해요.

```bash
python prism.py serve --port 8002
```

이 경우 **[http://127.0.0.1:8002](http://127.0.0.1:8002)**에 접속해요. 서버를 실행한 터미널에서 `Ctrl+C`를 누르면 종료돼요.

### 5. 웹 데이터만 다시 생성하는 경우

수집·분석이 완료된 결과로 웹 표시용 데이터만 다시 생성하려면 다음 명령어를 실행해요. 본문이나 자료가 바뀌어 분석이 오래된 경우에는 먼저 `prism.py update --run`으로 재처리해야 해요.

```bash
python -m prism_core.publishing.build
```

실행 결과는 `web/snapshots/`에 저장하고, 검증을 마치면 `web/current.json`에 반영해요.

### 6. 실행 결과 및 생성 파일

| 경로 | 내용 |
| --- | --- |
| `data/news_.../` | 뉴스 수집·본문·분석 결과 및 로그 |
| `web/current.json` | 현재 발행된 스냅샷의 경로와 수집 ID |
| `web/snapshots/` | 검증을 마친 뉴스 포털 데이터 |
| `web/demo.json` | 새 복제본에서 사용하는 비교 예시 데이터 |

수집 결과와 발행 스냅샷은 Git 추적 대상에서 제외돼요. `web/demo.json`은 저장소에 포함하며, `config/article_selections.json`을 수정했다면 `python prism.py demo`로 다시 생성할 수 있어요. 이 명령은 실제 발행 데이터를 교체하지 않아요.

변경 사항은 목적별로 커밋하고 일반 푸시로 저장해요.

## 📖 라이선스 및 이용 안내

Prism의 소스코드와 외부 뉴스 콘텐츠는 이용 조건을 구분하여 확인해야 합니다.

- **프로젝트 소스코드:** 저장소의 라이선스 파일 및 별도 이용 조건 확인
- **국가데이터처 RSS:** 원자료 제공기관의 이용 조건 확인
- **네이버 뉴스 검색 API:** 네이버 API 이용약관 및 제공 범위 준수
- **언론사 기사 본문·이미지:** 원문 제공기관의 저작권 및 이용 조건 확인

기술적으로 기사 본문이나 이미지를 추출할 수 있더라도, 해당 콘텐츠를 별도 웹사이트에 전문 게시하거나 재배포할 권한이 자동으로 부여되는 것은 아닙니다.

실제 서비스 공개 시에는 원문 콘텐츠의 이용 허용 범위를 확인하고, 필요한 경우 검색 요약문과 원문 링크를 중심으로 제공해야 합니다.

## ⚠️ 서비스의 한계 및 유의사항

- **검색 결과의 관련성:** RSS 제목을 기준으로 검색한 결과에 국가·기준연월·통계 대상이 다른 기사가 포함될 수 있습니다.
- **통계 검증 기능과의 구분:** 현재 Prism은 관련 뉴스 탐색 서비스이며, 기사 속 통계 수치를 공식 통계와 대조하여 사실 여부를 판정하는 기능은 구현 범위에 포함되어 있지 않습니다.
- **본문 추출 제한:** 언론사별 HTML 구조, 접근 정책, `robots.txt`, 서버 응답 등에 따라 본문 추출이 실패할 수 있습니다.
- **요약문 대체:** 본문 추출에 실패한 경우 검색 API의 요약문을 사용하므로 기사 전체 내용을 확인하기 어려울 수 있습니다.
- **대표 이미지 제한:** 원문 페이지에 이미지 정보가 없거나 추출할 수 없는 경우 기본 이미지가 표시될 수 있습니다.
- **연관 기사 해석:** 검색 기준으로 연결된 기사와 본문에서 자료 연결 근거를 찾은 기사를 구분해요. 자료명·링크·기간·수치에 기반한 규칙이므로 기사 전체의 관련성이나 통계적 정확성을 보증하지 않아요.
- **자동 주장 분석:** 같은 자료와 비교 가능한 문장을 대상으로 양방향 NLI 점수를 확인해요. 모델 정확도를 사람의 정답 데이터로 평가한 결과는 아직 없으며, 후보가 0쌍이어도 상반된 기사가 없다는 뜻은 아니에요.
- **데이터 갱신:** 뉴스 수집은 Python 스크립트 실행을 통해 수행되므로, 웹페이지에 표시되는 기사가 항상 실시간 최신 기사인 것은 아닙니다.
- **외부 서비스 의존성:** 네이버 뉴스 API 및 언론사 웹페이지의 응답과 이용 정책 변경에 따라 수집 결과가 달라질 수 있습니다.
- **저작권 및 이용 조건:** 기사 본문과 대표 이미지의 공개·재배포에는 별도 권리 검토가 필요합니다.
- **인증정보 보호:** 실제 API 키가 포함된 `.env` 파일은 GitHub에 업로드하지 않아야 합니다.
